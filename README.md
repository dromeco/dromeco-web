# dromeco.fi

Dromeco Productionsin yksisivuinen verkkosivu. Staattinen HTML/CSS, julkaistaan GitHub Pagesilla.

- `index.html` – koko sivu (tyylit ja skripti samassa tiedostossa)
- `img/` – kuvat ja DP-merkki
- `og.jpg` – jakokuva (LinkedIn, Facebook)
- `favicon.png`, `apple-touch-icon.png` – kuvakkeet

Tyyliopas: Dromeco HQ -projektissa `claude/DROMECO_Visuaalinen_tyyli_Web_v1.md`.
